HOW TO RUN
----------
1. Extract the ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. For the easiest preview, install/use the "Live Server" extension in VS Code and choose:
   "Open with Live Server".
5. The portfolio is a static website, so no Python/Django setup is required.

RESUME UPDATE IN THE FUTURE
---------------------------
The website already has View Resume and Download PDF buttons.

To replace your resume later:
1. Prepare your updated PDF.
2. Rename it to:
   resume.pdf
3. Replace:
   assets/resume.pdf
4. Keep the same filename and folder location.
5. Refresh the website.

If you prefer a different PDF filename, update the two href values in index.html inside the RESUME section.
